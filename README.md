 ## Descripción
En este repositorio subimos los dos ejercicios que hicimos para la tarea de funciones y procedimientos en C#:
1. **Tienda de repuestos:** Es un programa que calcula la factura de una compra, le aplica un 10% de descuento si el cliente es frecuente y le suma el 18% de ITBIS.
2. **Cuentas de estudiantes:** Es un programa que crea un nombre de usuario juntando la primera letra del nombre con el apellido y revisa si la contraseña es segura.

   # Analisis de datos de ambos

## 1. Sistema de facturación

### Entrada
- Nombre del cliente.
- Subtotal de la compra.
- Indicar si el cliente es frecuente.

### Proceso
1. Se verifica si el cliente es frecuente.
2. Si es frecuente, se aplica un descuento del 10 % al subtotal.
3. Se calcula el 18 % de ITBIS.
4. Se suma el subtotal con el ITBIS para obtener el total a pagar.

### Salida
- Nombre del cliente.
- Total final a pagar.



## 2. Sistema de creación de cuentas de estudiantes

### Entrada
- Nombre del estudiante.
- Apellido del estudiante.
- Contraseña que desea utilizar.

### Proceso
1. Se genera el nombre de usuario utilizando la primera letra del nombre y el apellido completo.
2. El usuario se convierte a letras minúsculas.
3. Se comprueba que la contraseña tenga al menos 8 caracteres.
4. Se verifica que la contraseña no contenga el nombre de usuario.
5. Se determina si la contraseña cumple con las condiciones establecidas.

### Salida
- Nombre de usuario generado.
- Resultado de la validación de la contraseña (válida o no válida).
